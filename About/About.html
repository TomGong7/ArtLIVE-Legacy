设计理念

古韵今风

以传统审美为底色，融合现代设计语言，简洁而不失韵味。

墨香纸韵

配色取自宣纸与青绿山水，低饱和度的自然色调，久看不倦。

留白之美

借鉴中国画"计白当黑"的构图理念，让内容在呼吸之间自然呈现。

笔触匠心

关注每一个交互细节，从圆角到过渡，追求质朴而精准的质感。

技术实现

前端

纯原生 HTML、CSS 与 JavaScript 构建，无框架依赖。采用 CSS 变量统一管理色彩与间距，响应式布局适配桌面与移动端。

数据存储

用户数据与生成作品基于 localStorage 本地存储，登录状态、收藏列表、社区帖子均在浏览器端持久化，无需后端服务。

智能创作

工坊模块接入大语言模型与图像生成接口，支持文生图、图生图、音乐生成与视频生成，为用户提供丰富的创作方式。

智能助手

基于大语言模型构建的国风艺术问答助手，可回答国画、书法、诗词、篆刻、艺术史等领域的相关问题。
